# Waffir NL / وفر NL

Arabic RTL static prototype for a Netherlands-inspired deals, products, and comparison platform.

## Preview

Open `index.html` or use GitHub Pages if enabled on this repository:

`https://nuvora-webpro.github.io/nuvora-previews/waffir-nl/`

## Design direction

- Palette: Netherlands-inspired royal blue, orange, red, white, dark navy
- No green theme
- Arabic RTL interface
- Modern comparison/product cards
- Mobile responsive
- Single-page static prototype using hash routes
